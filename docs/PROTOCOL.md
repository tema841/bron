**Окружение:**
- Сервер: `npm start`, http://localhost:8080.
- Перед проверкой выполнен `npm run seed`.
- Сессии:
  - ivanov — браузер, обычное окно;
  - petrova — второй профиль или окно инкогнито;
  - admin — третий профиль.
- Отдельные запросы отправлялись через Postman.

Обозначения: **Д** — дата проверки, например на 3–5 дней вперёд. **R** — номер ресурса.
