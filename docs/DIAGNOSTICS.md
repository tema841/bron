# Диагностика

## Два журнала

| Журнал | Где | Для чего |
|---|---|---|
| Технический | `logs/app.log` (JSON-строки) и консоль сервера (в Render: вкладка Logs) | Каждый запрос к API (метод, путь, статус, пользователь, время), отказы доступа (401/403), непредвиденные ошибки со стеком |
| Аудит | Таблица `audit_events`, в интерфейсе: «Администрирование» → «Аудит» | История действий: создание и отмена броней, создание, изменение, отключение и включение ресурсов, отклонённые попытки брони |

В событии указываются время, исполнитель, действие, объект, результат и `traceId`.

Пароли, JWT, заголовок `Authorization` и строка подключения в журналы не записываются.

## Как найти ошибку по traceId

1. В ответе об ошибке, в заголовке `X-Trace-Id` или в интерфейсе («Код для поддержки») скопируйте traceId.
2. Найдите его в техническом журнале:

   ```bash
   # Windows (PowerShell)
   Select-String -Path logs\app.log -Pattern "5b6023a0-7442-423f-a74e-755aab3e5576"
   # Linux/macOS
   grep 5b6023a0-7442-423f-a74e-755aab3e5576 logs/app.log
   ```

3. Если это действие с бронью, то же значение есть в аудите:

   ```sql
   SELECT * FROM audit_events WHERE trace_id = '5b6023a0-7442-423f-a74e-755aab3e5576';
   ```

## Проверка готовности

| Адрес | Норма | Что значит отклонение |
|---|---|---|
| `/health/live` | `200 {"status":"ok"}` | Нет ответа — процесс не запущен |
| `/health/ready` | `200 {"status":"ready"}` | `503` — сервер работает, но БД недоступна |

## Проверка БД

```bash
psql -U postgres -d bron -c "SELECT name, applied_at FROM schema_migrations"
psql -U postgres -d bron -c "SELECT status, count(*) FROM bookings GROUP BY status"
```

Типовые проблемы:

| Симптом | Причина | Что делать |
|---|---|---|
| При запуске «Не задана переменная окружения …» | Нет `.env` | Скопировать `.env.example` в `.env` и заполнить |
| `/health/ready` → 503 | PostgreSQL не запущен или неверный `DATABASE_URL` | Проверить службу PostgreSQL и строку подключения |
| `relation "bookings" does not exist` | Не выполнены миграции | `npm run migrate` |
| `extension "btree_gist" is not available` | Неполная установка PostgreSQL | Переустановить PostgreSQL с contrib-модулями (стандартный установщик их содержит) |
| Все запросы 401 | Изменён `JWT_SECRET` или истёк токен | Войти заново |
